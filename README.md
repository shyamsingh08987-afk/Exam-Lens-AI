# ExamLens AI 🎓

AI-powered exam analysis and personalized learning platform for students.

## 🚀 Problem

Students often receive exam marks but do not understand:
- Which topics they are weak in
- Why they made mistakes
- What they should study next
- How to improve their performance

## 💡 Solution

ExamLens AI analyzes exam performance and converts results into actionable learning recommendations.

### Key Features

- 📊 Exam performance dashboard
- 🤖 AI-powered performance analysis
- 🎯 Weak-topic detection
- 📚 Personalized study plan
- ✍️ Targeted practice questions
- 📈 Progress tracking
- 🎓 Student-friendly interface

## 🛠️ Technology

- React
- TypeScript
- Tailwind CSS
- Vite
- AI-powered recommendation logic

## 👨‍💻 Hackathon Project

Built as a solo hackathon project focused on improving personalized education.

## 🎯 Vision

Help every student understand not just **what their score is**, but **how they can improve it**.
